phpXFace Front Controller
=========================

This is a corresponding front controller for phpXFace.

Composer Install
=================
```json
{
    "require": {
        "phpxface/frontcontroller": "dev-master"
    }
}
```

History
-------

phpXFace started in 2013 as a personal side project to explore building an annotation‑based micro API framework for PHP. The goal was to make API‑first development simple and fast while experimenting with design patterns, performance tuning, and profiling techniques.

By 2013–2014 the framework was functional and used to validate ideas like:
- Annotation‑driven controllers and dependency injection
- An XML‑based UI/component model inspired by Android and JavaFX
- Modular, plugin‑oriented application structure for larger SaaS projects

Although the core worked at the time, the project remained largely untouched for years. In the meantime, several actively maintained frameworks emerged with similar concepts and broader ecosystems. That evolution reinforced the original learning purpose of phpXFace: to understand frameworks from the inside out and gain hands‑on experience with architecture, performance, and tooling.

Today the project is published openly for anyone curious about these ideas. Feel free to read the code, experiment, fork it, or adapt parts of it to your own needs. Contributions and issue reports are welcome.
